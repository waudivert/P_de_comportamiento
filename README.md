# Plantilla de patrones de comportamiento – WPF

Solución para Visual Studio 2026, C#, WPF y .NET 10. Se reutiliza el estilo verde de la plantilla de dos patrones.

## Patrones incluidos

1. Chain of Responsibility (`ChainOfResponsibility`)
2. Command (`Command`)
3. Iterator (`Iterator`)
4. Mediator (`Mediator`)
5. Memento (`Memento`)
6. Observer (`Observer`)
7. State (`State`)
8. Strategy (`Strategy`)
9. Template Method (`TemplateMethod`)

Cada carpeta tiene una vista `.xaml`, un archivo `.xaml.cs`, carpetas preparadas para los componentes y archivos README. Las vistas están conectadas desde `MainWindow` y son **plantillas vacías**: no contienen ejemplos implementados aún.

## Uso

Abre `Patrones_Comportamiento.sln` (o `.slnx`) en Visual Studio con la carga de trabajo de desarrollo de escritorio .NET y .NET 10. Compila y ejecuta. Cada integrante puede trabajar en la carpeta de su patrón.

Recomendación de Git: una rama por patrón y merges a la rama compartida después de probar los cambios.
